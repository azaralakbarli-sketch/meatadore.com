# meatadore.com
Static site for Meatadore burger restaurants (Baku). Hosted on GitHub Pages.
- `index.html` — home; `menu.html` — full menu
- `menu-data.js` — all products & prices (edit here for price changes)
- `site.js` — phone/WhatsApp/links config (top of file), branches, rendering
- `assets/menu/` — product photos; `assets/web/` — brand & interior photos
